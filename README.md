## Usage

### Fitting a sine wave
```bash
python3 -m bokeh serve --show prototype.py
```

or

If you have uv:
```bash
uv run bokeh serve --show prototype.py
```

### MNIST digit detection
```
python3 mnist_detection.py
```

or

If you have uv:
```bash
uv run mnist_detection
```
